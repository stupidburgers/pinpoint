# Pinpoint - build spec (v1, frozen interfaces in section 4)

Repo target: `stupidburgers/pinpoint`. This folder (`plugin/pinpoint/`) IS the repo root. Decisions: `decisions/002-chosen-idea.md`, `decisions/003-q5.md`.
Status legend: **[M]** measured on the installed build (Hermes Desktop 2026.7363.3271.0, agent 0.22.7, Windows 11); **[D]** designed, not yet run; **[S]** from SDK docs/source, not run.

## 1. One-sentence pitch and differentiation
Hermes Desktop measures the live page in the Browser pane with deterministic in-page audits, pins numbered markers on the real elements, one click sends a pin to the agent as a fix task, and when the page changes it re-audits so pins turn green with a score delta.

| Neighbour (read in this repo) | What it does | Pinpoint differs |
|---|---|---|
| impeccable `skill/hermes-plugin` | hooks `transform_tool_result` (write_file/patch) + `pre_verify`; shells out to a CLI detector on UI **source files**; findings go to the model as text | Pinpoint measures the **rendered page** (computed styles, real layout), has a **visual overlay**, no subprocess, no hook |
| `redline` (silentpr0) | review pane for Markdown/code; annotations -> sidecar json | different object (documents vs live UI); no measurement |
| `word-peek` | reads an HTML passage / browser **selection** read-only through `ctx.preview`, asks the model | Pinpoint audits the whole page by rule and draws on it; uses the same consent door but writes nothing to disk but its own DB |
| `hardlight-ui` (catalog) | design guidance + stateless tools for **source** inspection, a contrast calculator, optional Chromium launcher | Pinpoint = live page in the Desktop pane, overlay, verified fix loop |
| `hermes-ios` (catalog) | native iOS visual iteration via localhost | different platform; no audit/overlay |
| `preview-text-size` (catalog) | scales text in the file preview pane | unrelated |
Claim to keep honest: "no catalog entry found that draws measured findings on the live Browser pane" (grep of descriptions for preview/a11y/contrast/wcag in `research/hermes-agent/plugin-catalog/*.yaml`, 2026-11-04). It is a grep of descriptions, not of source.

## 2. Architecture
```
 agent turn                          gateway process (same pid [M])                 Desktop window (renderer)
 ----------                          -------------------------------                ------------------------
 model --tool_call--> pinpoint_audit handler --broadcast plugin.pinpoint.audit.request--> desktop/plugin.js
                          |  poll data dir 50ms <---- ctx.rest POST /ack, /result ---------|  ctx.preview.executeJavaScript
                          v                                                                |      |
                   tool result (compact JSON) --> model                          in-page engine (window.__pinpoint)
 user click pin -> engine queue -> desktop poll drain() -> host.composer.submit(null,"Pinpoint: fix ...") -> agent
 page changes -> engine 'dirty' -> desktop poll -> re-audit -> diff vs store -> pins green + score delta
```
Three artifacts:
1. **Engine** `engine/pinpoint-engine.js`: ONE self-contained function `pinpointEngine(config)`, pure browser JS, zero deps, installs `window.__pinpoint`. Source of truth + tested in real Chromium.
2. **Desktop half** `desktop/plugin.js` = GENERATED by `scripts/build-desktop.mjs` from `desktop/src/app.js` + the engine function inlined as a declaration (disk plugins are uncompiled and cannot import siblings [S]). The engine reaches the page as `'(' + pinpointEngine.toString() + ')(config)'` (pattern proven in spike [M]).
3. **Python half**: tools, REST routes, SQLite store, system-prompt section. No hooks, no middleware, no subprocess, no network.

## 3. Q5 summary (full: `decisions/003-q5.md`)
Rendezvous: tool broadcasts `audit.request`, desktop acks + posts result over `ctx.rest`, handler returns it as the tool result [M: 23 ms / 300 findings 30 ms / 25 s wait ok]. Desktop->agent: `host.composer.submit(null,text)` [M]. Fallback: desktop-only mode (section 8).

## 4. FROZEN CONTRACTS (all packages code against these; change only via lead)

### 4.1 Engine API (B implements, C consumes)
`window.__pinpoint = { protocol:1, version:'0.1.0', audit, render, setStatuses, focusPin, clear, drain, probe, destroy }`
Install is idempotent: if `window.__pinpoint?.version === own version` the factory returns the existing object; if older, calls `destroy()` on it first.
```
audit(opts?) -> AuditResult                      // synchronous, never throws (errors -> result.errors[])
  opts: { rules?: string[], tapMin?: 24, tapAdvisory?: 44|0, contrast?: 'AA'|'AAA', maxFindings?: 200, suppress?: string[] /*finding ids*/ }
render(findings: Finding[], opts?: {statuses?: Record<id,Status>, pinLimit?: 60}) -> { pinned:number, lost:string[] }
setStatuses(map: Record<id,'open'|'fixed'|'dismissed'|'new'>) -> void
focusPin(id) -> boolean                          // scrolls target into view (block:'center'), flashes outline
clear() -> void                                  // removes overlay root + observers' work (observers stay for dirty detection)
drain() -> EngineEvent[]                         // empties queue
probe() -> { protocol, version, url, key, ready, pins, dirty, vw, vh, docVersion }   // <= 300 bytes, called every 500-1000 ms
destroy() -> void                                // removes overlay, observers, listeners, window.__pinpoint
EngineEvent = {type:'pin-click',id,t} | {type:'fix',id,t} | {type:'dismiss',id,t} | {type:'dirty',reason:'mutation'|'load'|'resize'|'navigation',t}
Status = 'open'|'fixed'|'dismissed'|'new'
```
`AuditResult`:
```
{ protocol:1, url, key, title, viewport:{w,h,dpr}, scroll:{w,h}, t, score:0..100, counts:{high,medium,low},
  byRule:{[ruleId]:number}, findings:Finding[], stats:{elements,ms,checked:{[ruleId]:number}},
  limits:string[], errors:{rule,message}[] }
```
`Finding`:
```
{ id:'<rule>@<8 hex>', rule, sev:'high'|'medium'|'low', wcag?:'1.4.3', heuristic?:true, confidence:'high'|'medium',
  selector, label, note, fix, measured:{...rule specific, numbers/hex only},
  rect:{x,y,w,h} /*page coords at audit time*/, anchor:{tag,role,name,textHash,ref,path,nameAttr}, pin?:number }
```
- `id` = `rule + '@' + hex8(fnv1a(fingerprint))`; `fingerprint` = `rule|tag|role|stableKey|ancestorPath` where `stableKey` = first available of unique stable `id`, `name`, `href` (origin-stripped), `src` basename, normalised visible text (first 40 chars, lowercased, whitespace-collapsed) and never includes `class`, `style`, `alt`, label text, rects, or `nth-*` indices of unstable nodes. Rationale: the fix the agent makes (adding alt/label/colour/size) must not change the id, so "fixed" = id absent next audit. Hash must NOT use bit shifts (installer scanner flagged `h << 5` in shader-forge [M]); use `Math.imul`.
- `selector`: robust order: (1) `#id` if unique and not generated (reject `/\d{4,}|[0-9a-f]{8,}|^(radix-|:r|react-|ember)/i`); (2) tag + `[name=..]` / `[href=..]` / `[src$=..]` if unique; (3) nearest stable ancestor selector + `>` path using `:nth-of-type`, classes allowed only if not hashed (reject `/^(css|sc|jsx|_)[-_]?[a-z0-9]{5,}$/i`, `/^[a-z]{1,3}[0-9a-f]{5,}$/`). Max 200 chars, charset `[\w#.\-:>\[\]="'()*~+,/ ]` else dropped to the tag path.
- Re-resolution each render: try selector; accept only if `tag` and (`textHash` or `ref`) match the anchor; else score same-tag candidates (textHash 3, ref 3, nameAttr 2, ancestor path similarity 0..2, rect proximity 0..1) accept >= 4; else `lost` (pin hidden, row marked "can't locate").
- Page text (label, anchor text) is **untrusted data**. Engine strips control chars, truncates label to 40 chars.
- Score: `100 - sum(w(sev) * k)` clamp 0..100, `w = {high:8, medium:4, low:1}`, per rule the first 5 findings count `k=1`, the rest `k=0.25`. Integer, rounded half up. Deterministic, unit-tested.
- Own overlay is excluded from every rule and from observers (`[data-pp-root]`). Forbidden strings in engine source (catalog `desktop surface` lint [M]): `MutationObserver` observing `document.body` (use `document.documentElement`), literals `data-testid` / `data-slot`; also keep out `eval`, `new Function`, `<script`, `import(` and bit-shift hashing.

### 4.2 Python <-> Desktop protocol (A implements server, C implements client)
Plugin id on the wire: `pinpoint` (events `plugin.pinpoint.<event>`).
| Direction | Mechanism | Payload |
|---|---|---|
| Py -> Desktop | `broadcast_plugin_event('pinpoint','audit.request',{request_id,args,session_id})` | `args` = tool args after validation |
| Py -> Desktop | `broadcast_plugin_event('pinpoint','pins.changed',{url_key})` | after `pinpoint_pins` mutates the store |
| Desktop -> Py | `POST /api/plugins/pinpoint/ack/{request_id}` body `{window:string}` -> `200 {claimed:true}` or `409 {claimed:false}` (exclusive-create file) | |
| Desktop -> Py | `POST /result` body `{request_id, ok:true, result:AuditResult}` or `{request_id, ok:false, code, message}` | `code` in `no_preview|consent_denied|origin_blocked|page_unreachable|engine_error|navigated` |
| Desktop -> Py | `POST /audit` body `{result:AuditResult, source:'user'|'auto'}` (user-initiated audits, no request) | stored, returns `{audit_id, delta}` |
| Desktop <- Py | `GET /store?url_key=` -> `{pins:[{id,status,finding,first_seen,last_seen,reason?}], last:{audit_id,score,t}}`; `GET /pending` -> unanswered, unacked requests < 120 s old; `GET /health` -> `{ok:true,version,pid}` | used on register / reconnect |
| Desktop -> Py | `POST /pins` body `{action:'dismiss'|'reopen'|'clear', url_key, ids?, reason?}` | |
Rendezvous files under `plugin_data_dir('pinpoint')/rv/<request_id>.{req,ack,res}.json` [M: same approach used in the probe]. Handler waits: ack up to `ack_timeout_s`, result up to `audit_timeout_s`. Handler ALWAYS returns a JSON string; deletes rv files on exit; sweeps rv files older than 10 min on register.

### 4.3 Store (SQLite via `plugins.plugin_storage.plugin_db('pinpoint')`)
`audits(id INTEGER PK, url_key TEXT, url TEXT, t REAL, score INT, counts TEXT, source TEXT)`, `pins(url_key TEXT, id TEXT, status TEXT, finding TEXT, first_seen REAL, last_seen REAL, reason TEXT, PRIMARY KEY(url_key,id))`. LRU: keep 20 `url_key`s, 200 pins per key, 50 audits per key (prune on write). `url_key` = `origin + pathname` (+ `#/route` when hash starts with `#/`, + sorted query minus `utm_*`,`fbclid`,`gclid`), lowercase host, trailing slash stripped. Delta: `fixed` = pins `open|new` in previous audit and absent now; `new` = id absent from all previous pins of that key; `remaining` = present in both; `dismissed` ids never counted and never returned as findings.

### 4.4 Tool I/O (section 6 has descriptions)
Result cap 12 000 chars (the model saw 76 KB untruncated in the probe [M], but the desktop `tool.complete` event truncates at ~35 KB [M]; compactness is for model context). Fields dropped first: `rect`, `anchor`, `measured` extras, then findings beyond `max_findings` (`truncated:true`).

## 5. Audit rules (14, stable ids; B implements, fixtures in `tests/engine/fixtures/`)
All thresholds are WCAG 2.2 unless noted. `hint` = template for `fix`.
| id | sev | WCAG | Detects | Algorithm notes |
|---|---|---|---|---|
| `a11y.contrast` | high if ratio<3 else medium | 1.4.3 (AAA 1.4.6) | text below 4.5:1 (3:1 large: >=24px, or >=18.66px and weight>=700); AAA 7/4.5 | per element with an own non-blank text node that is rendered (client rects, `visibility`, `display`, clip). fg = computed `color` with alpha, multiplied by cumulative ancestor `opacity`, composited over resolved bg. bg resolve: walk ancestors compositing semi-transparent `background-color` until opaque alpha>=0.99; stop at root -> white (`color-scheme: dark` -> canvas from `getComputedStyle(documentElement).backgroundColor` if opaque). **Skip + record in `limits`/`stats.skipped` when any ancestor has `background-image` (gradient/url) before an opaque colour** - never report a guess. Skip disabled/`aria-disabled` controls (WCAG exempts inactive). Color parsing: `rgb()/rgba()` direct; `color(srgb ...)` direct; any other (`oklch`, `lab`, `color-mix` result) via 1x1 canvas `fillStyle` + `getImageData` [D, test with fixtures]. `fix`: smallest HSL-lightness change of fg that reaches need+0.05, returned as hex. |
| `a11y.tap-target` | medium if <24 ; low if 24..43 (advisory, `tapAdvisory:44`) | 2.5.8 / 2.5.5 | `a,button,input,select,textarea,summary,[role=button|link|checkbox|tab|menuitem],[tabindex>=0]` rendered rect smaller than min in either axis | exempt: inline links inside running text (parent is `p/li/span` text flow and `display:inline`), `input[type=hidden]`, targets whose 24px-diameter circle centered on the target does not intersect another target's rect (WCAG spacing exception), sr-only clipped elements. measured `{w,h,min}`. |
| `a11y.img-alt` | high | 1.1.1 | `<img>` without `alt` attribute; `alt` that looks like a filename (`/\.(png|jpe?g|gif|svg|webp)$/i`, `/^img[_-]?\d+/i`); `role=img` / `<svg role=img>` / `input[type=image]` with no accessible name | `alt=""` is valid (decorative) when no `role` contradicts. |
| `a11y.form-label` | high | 1.3.1 / 4.1.2 / 3.3.2 | `input` (not hidden/submit/button/reset/image), `select`, `textarea` with no accessible name | name sources, in order: `aria-labelledby` (all ids exist and non-empty text), `aria-label` non-blank, `label[for=id]`, wrapping `label`, `title`. `placeholder` alone = finding (note says so). |
| `a11y.control-name` | high | 4.1.2 | `button`, `a[href]`, `[role=button|link|tab|menuitem]` with empty accessible name (no text, no aria-label/labelledby, no img alt, no title) | icon-only buttons are the main hit. |
| `a11y.heading-order` | low | 1.3.1 / 2.4.6 | level jumps (h2 -> h4), no `h1`, multiple `h1`, empty headings | `role=heading aria-level` honoured. Page-level findings anchor to the first offending heading or `<body>`. |
| `a11y.focus-indicator` | medium, `heuristic:true`, confidence medium | 2.4.7 | focusable element whose author CSS removes the focus indicator with no replacement | Static CSSOM scan, NO `.focus()` calls (focus handlers could mutate the app). For each focusable el: collect same-origin stylesheet rules (`document.styleSheets`, try/catch per sheet; cross-origin sheets -> `limits.push('cross-origin stylesheets not scanned: N')`) whose selector (pseudo-classes `:focus|:focus-visible|:focus-within` stripped) matches the el; flag if (an author rule sets `outline: none|0` or `outline-style:none` on el or its `:focus(-visible)` state) AND no matching `:focus(-visible)` rule sets a non-none `outline`, `box-shadow`, `border-color`, `background(-color)`, `text-decoration` or `filter`. UA default ring (no author rule touching outline) = pass. |
| `a11y.lang` | medium | 3.1.1 | `<html>` without non-empty `lang` | anchor `html`. |
| `a11y.page-title` | low | 2.4.2 | empty/missing `<title>` | |
| `a11y.viewport-zoom` | medium | 1.4.4 | `<meta name=viewport>` with `user-scalable=no` or `maximum-scale<2` | |
| `layout.h-overflow` | medium | 1.4.10 | document wider than viewport (`scrollWidth > clientWidth + 1`) -> report root-cause elements | candidates: rendered els with `rect.right > vw + 1`; exclude descendants of `overflow:auto|scroll|hidden|clip` ancestors, `position:fixed` offscreen skip-links, `visibility:hidden`; keep outermost offender whose parent does not also exceed; max 5; sorted by overflow px. measured `{over, vw}`. |
| `type.text-small` | medium if <10px, low if <12px | 1.4.4 (best practice) | rendered text whose computed `font-size` < 12px | skip `sub/sup`, `font-variant: small-caps` ok; measured `{px}`. |
| `type.line-height` | low | 1.4.12 | multi-line (>=2 client rects) paragraphs with `line-height < 1.2 * font-size` (computed px; `normal` skipped) | |
| `spacing.tight-targets` | low | 2.5.8 | two interactive targets < 44px in either axis whose border boxes are < 8px apart (and not nested) | measured `{gap}`. report the pair once (anchor the second). |
Common `limits`: cross-origin stylesheets, closed shadow roots (open shadow roots ARE traversed), iframes (same-origin traversed up to depth 2; cross-origin skipped and counted).
Engine performance budget: <= 400 ms and <= 5 000 elements on a mid page; if more than 5 000 elements, audit viewport +- 2 screens only and push `limits`.

## 8. Desktop half (C implements)
Surfaces: palette commands `Pinpoint: audit page`, `Pinpoint: re-audit`, `Pinpoint: clear pins`, `Pinpoint: send all high-severity to agent`; right pane "Pinpoint" (`PANES_AREA`, placement right, 340px); status-bar chip (`STATUSBAR_AREAS.right`, order 140) showing score and delta, click = audit; no JSX (use `jsx/jsxs` [S]).
State: `ctx.storage` = UI prefs only (`autoReaudit` default true, `tapAdvisory`, `contrast`, `grants:{origin:true}` hint, `lastKey`). Pins/audits live in the Python store (section 4.3); if `GET /health` 404s -> **desktop-only mode**: keep last audit/pins in `ctx.storage` keyed by `url_key`, disable agent features, chip tooltip "Python half off".
Lifecycle:
1. `register`: `host.onEvent('plugin.pinpoint.audit.request')`, `...pins.changed`; `GET /health`; if `ctx.storage.lastKey` has stored pins, adopt overlay from page if engine present else wait for next audit (spike lesson: hot-reload recreates module state [M]); `GET /pending` once, then on window focus.
2. Request handler: if `!ctx.preview.isAvailable()` ignore (do not ack). Else `POST /ack/<id>` (409 -> stop). If origin grant unknown: `host.notify` "Pinpoint will ask permission to run on <origin>"; call `ctx.preview.executeJavaScript(inject)`; map rejection text -> `code` (`not allowed` -> `consent_denied`, `No preview page` -> `no_preview`, `changed origin` -> `navigated`, non-web origin -> `origin_blocked`). Run `audit(opts)`, `render(findings)` when `pin:true`, `POST /result`.
3. Poll loop `ctx.setInterval` 1000 ms (500 ms while pins shown): `probe()`; if `engine` missing (full reload/navigation) and a stored pin set exists for the new `url_key` -> re-inject, wait `readyState==='complete'` + 600 ms quiet, auto re-audit (if `autoReaudit`); if `dirty` -> debounce 800 ms quiet then re-audit; `drain()` events: `pin-click` opens card (in-page), `fix` -> compose prompt -> `host.composer.submit(null, text)` [M]; if it returns false -> `host.composer.insertText(null, text, {mode:'block'})` [M in spike] + toast "Open a chat to send"; `dismiss` -> `POST /pins`.
4. Re-audit: `POST /audit {source:'auto'}` -> delta -> `setStatuses` (fixed = green check, fades from overlay after 8 s, stays in pane list), toast "Pinpoint: 62 -> 91 (+29), 3 fixed". Rate limit: <= 1 audit / 2 s, <= 30 auto re-audits / min; stop and show "paused (page changing too fast)" beyond.
5. Pin prompt (<= 700 chars), template:
```
Pinpoint: fix pin #3 [a11y.contrast] on http://localhost:5173/
Element: button.cta "Start free trial"  selector: `#hero .cta`
Measured: contrast 1.92:1, needs 4.5:1 (fg #aaaaaa on #ffffff). Suggested: #6b6b6b or darker.
Change the SOURCE (not built output). Pinpoint re-audits on reload; or call pinpoint_audit to verify. finding id: a11y.contrast@1f3a9c2b
```
"Fix all high" = one message listing <= 8 findings. Never auto-submit without a user click (visible user bubble is the only mode available [M]).
Consent UX (host dialog text/buttons are NOT customisable [M spike]): first-run card in the pane titled "Allow Pinpoint to inspect pages?" explaining: "Hermes will ask 'Let Pinpoint run scripts on this page?' Choose *Allow on this site*. Revoke any time: Capabilities > Plugins > Pinpoint." with button "Audit this page" so the dialog is expected; agent-initiated first call shows the pre-toast above. *Don't allow* => `consent_denied`, pane shows "Denied for this session. Restart Desktop or revoke/regrant under Capabilities." (documented behaviour [S]; the Deny path was NOT run in the spike).
Multi-window: only a window with `ctx.preview.isAvailable()` acks; the ack claim is exclusive on the server [D].

### 8.1 Pin layout (engine; B implements, C styles via config)
